# WebSocket Warehouse Demo

A simple Node.js project demonstrating real-time communication using **WebSockets**.  
This system simulates a warehouse inventory that updates dynamically and broadcasts changes to connected clients.

---

## 🚀 Features
- Real-time stock updates via WebSocket connections  
- Mock API simulating warehouse inventory changes  
- Client interface displaying live inventory data  
- Easy setup and local testing environment  

---

## 🧩 Project Structure
| File | Description |
|------|--------------|
| `server.js` | WebSocket server handling connections and broadcasting updates |
| `mock-api.js` | Simulated warehouse API that updates stock quantities |
| `client.js` | Client-side script connecting to the WebSocket server |
| `index.html` | Front-end interface for viewing live inventory |
| `package.json` | Project dependencies and metadata |
